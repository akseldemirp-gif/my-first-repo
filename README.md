## Version Control Workflow

The basic workflow is:

1. Clone the remote repository to your computer.
2. Edit and save a file in the local repository.
3. Stage the changes and commit them with a descriptive message.
4. Push the commit to GitHub and check the updated file.

Repeat the edit, commit, and push steps whenever you make another change.

## Pull Request Workflow

Use a feature branch to prepare a change and review it before merging it into `main`:

1. Check out `main`, then fetch and pull the latest changes from GitHub.
2. Create and check out a new feature branch.
3. Edit and save a file, stage the changes, and make a descriptive commit.
4. Push the feature branch to GitHub.
5. Open a pull request comparing the feature branch against `main`.
6. Review the changes in the pull request.
7. Merge the pull request on GitHub when the changes are ready.

Before starting another change, return to `main` and fetch and pull the merged changes.
